# ハンドベル譜面

ハンドベルの譜面を作成・試奏・共有するWebアプリ（静的SPA、サーバ不要）。

- 譜面は「音名グリッド」形式: 縦に音名（高音が上）、横に拍。各音名の左に担当者名、右端に各音の出現回数
- 既定の音域は **3A〜5E**（半音含む20本）。曲ごとにツールバーで変更可
- 試奏モード: 再生位置の表示、鳴らす音のハイライト、譜面を流す表示（音ゲーのように再生位置を固定して譜面がスクロール）、ループ、開始小節の指定
- 共有: JSONの書き出し/読み込み、MusicXMLの書き出し/読み込み（.musicxml / .xml / .mxl。MuseScore などの楽譜ソフトとやり取り）、共有URL（譜面データをURLに埋め込み）、印刷（A4横）
- 作った曲はブラウザ（localStorage）に保存

## 使い方

```sh
npm install
npm run dev      # 開発サーバ
npm run test     # 単体テスト
npm run build    # dist/ に静的ファイルを出力（どこに置いても動きます）
```

### 操作

| 操作 | 方法 |
| --- | --- |
| 音符を置く | マスをクリック |
| 響かせる長さ | 置くときにそのまま右へドラッグ / 既存の音符をドラッグ |
| 音符を消す | 音符をクリック |
| 担当者名 | 行左端の「名前」欄に入力（同じ名前は同じ色） |
| 音の確認 | 音名をクリック |
| 再生/停止 | ▶ ボタン または スペースキー |
| 再生開始位置 | 小節番号の行をクリック |
| 元に戻す/やり直し | Ctrl+Z / Ctrl+Y |

音名はオクターブ番号＋音名（例: `4A` = 440Hz）。

## サンプル曲の追加

1. アプリで曲を作り、「JSON書き出し」で `*.bellscore.json` を保存
2. そのファイルを `src/samples/` に置く
3. `npm run build`（開発中は自動反映）

`src/samples/` 内の `*.bellscore.json` はすべて自動でサンプル一覧に載ります。
同梱の `twinkle.bellscore.json`（きらきら星）は動作確認用なので、不要なら削除してください。
